# Godot Local AI Agent — Server & Godot Integration Bridge

This module provides a local HTTP server and Godot 4 integration bridge that allows your fine-tuned Godot model (`godot-agent-lora`) to create, edit, delete, and inspect Godot scenes, scripts, and projects directly.

---

## 1. System Architecture

```
┌────────────────────────────────────────────────────────┐
│                    Godot 4 Project                     │
│             (Game / Editor / Plugin Dock)              │
│                [godot_ai_bridge.gd]                    │
│   - create_scene()   - edit_scene()   - delete_scene() │
│   - request_action() - request_chat() - get_scene()    │
└───────────────────────────┬────────────────────────────┘
                            │ HTTP (JSON / REST)
                            ▼
┌────────────────────────────────────────────────────────┐
│                godot_agent_server.py                   │
│             (Port 8000 / Threaded Server)              │
│   - Endpoints: /v1/scene/create, /v1/scene/edit, etc.  │
│   - Godot 4 TSCN Scene Builder & AST Modifier          │
│   - Action Schema Validator & Traversal Protection     │
└───────────────────────────┬────────────────────────────┘
                            │ Inference
                            ▼
┌────────────────────────────────────────────────────────┐
│            Qwen2.5-Coder-7B-Instruct                   │
│            + godot-agent-lora Adapter                  │
│            (Loaded in 4-bit bfloat16)                  │
└────────────────────────────────────────────────────────┘
```

## 2. Structured Action Schema

All actions generated by the model conform to [`logic/schemas/godot_action.schema.json`](../logic/schemas/godot_action.schema.json):

```json
{
  "thought": "Reasoning explaining why this action was selected",
  "action_type": "create_scene" | "edit_scene" | "delete_scene" | "create_or_update_script" | "create_or_update_scene" | "read_file" | "list_project_files" | "run_project" | "chat_response",
  "parameters": {
    "file_path": "scenes/player.tscn",
    "root_node_name": "Player",
    "root_node_type": "CharacterBody2D",
    "content": "Full Godot 4 GDScript code or TSCN definition without markdown wrappers",
    "script_path": "res://scripts/player.gd",
    "overwrite": false,
    "add_nodes": [
      { "name": "CollisionShape2D", "type": "CollisionShape2D", "parent": "." }
    ],
    "remove_nodes": ["OldNode"],
    "command": "--headless --path .",
    "message": "Conversational message"
  }
}
```

## 3. Starting the Server

### Normal Mode (Loads GPU Model & LoRA Adapter):
```bash
python3 godot_agent_server.py --port 8000 --project-path /path/to/godot_project
```

### Mock Mode (Testing Endpoints without Loading Model Weights):
```bash
python3 godot_agent_server.py --port 8000 --no-model --project-path /path/to/godot_project
```

## 4. REST API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/health` | Check server and GPU status |
| `GET` | `/schema` | Retrieve the `GodotAgentAction` JSON Schema |
| `GET` | `/v1/scene?file_path=...&project_path=...` | Read and inspect an existing `.tscn` scene |
| `POST` | `/v1/scene/create` | **Create Scene**: Generate a valid Godot 4 `.tscn` scene with root node, script, or raw content |
| `POST` | `/v1/scene/edit` | **Edit Scene**: Update scene text or apply structured node additions, removals, and script attachments |
| `POST` / `DELETE` | `/v1/scene/delete` or `DELETE /v1/scene` | **Delete Scene**: Safely delete a `.tscn` scene and its sidecar metadata (`.uid`, `.remap`) |
| `POST` | `/v1/chat` | Natural language chat and GDScript advice |
| `POST` | `/v1/action` | Generates a structured JSON action based on prompt & project context |
| `POST` | `/v1/execute` | Executes an action directly on a Godot project folder safely |
| `POST` | `/v1/act` | End-to-end: generates action, validates it, and executes it on the project |

## 5. Integrating with Godot 4

1. Copy [`godot_ai_bridge.gd`](./godot_ai_bridge.gd) into your Godot project (e.g. `res://addons/godot_ai/godot_ai_bridge.gd`).
2. Attach it to a Node or register it as an Autoload.
3. Call it from any GDScript to create, edit, and delete scenes:

```gdscript
extends Node

var ai_bridge: GodotAIBridge


func _ready() -> void:
	ai_bridge = GodotAIBridge.new()
	ai_bridge.server_url = "http://127.0.0.1:8000"
	ai_bridge.auto_apply_actions = true  # Automatically applies received AI actions
	add_child(ai_bridge)

	# Connect bridge signals
	ai_bridge.scene_created.connect(_on_scene_created)
	ai_bridge.scene_edited.connect(_on_scene_edited)
	ai_bridge.scene_deleted.connect(_on_scene_deleted)
	ai_bridge.chat_completed.connect(_on_chat_completed)
	ai_bridge.action_received.connect(_on_action_received)

	# 1. CREATE SCENE
	ai_bridge.create_scene(
		"scenes/player.tscn",
		"CharacterBody2D",
		"Player",
		"",  # optional raw content (empty auto-generates Godot 4 TSCN)
		"res://scripts/player.gd"
	)


func _on_scene_created(success: bool, path: String, details: Dictionary) -> void:
	if success:
		print("Scene created successfully: ", path)

		# 2. EDIT SCENE (Add a CollisionShape2D node)
		ai_bridge.edit_scene(
			"scenes/player.tscn",
			"",
			[{"name": "CollisionShape2D", "type": "CollisionShape2D", "parent": "."}]
		)


func _on_scene_edited(success: bool, path: String, details: Dictionary) -> void:
	if success:
		print("Scene edited successfully: ", path)

		# 3. DELETE SCENE (when needed)
		# ai_bridge.delete_scene("scenes/player.tscn")


func _on_scene_deleted(success: bool, path: String, details: Dictionary) -> void:
	if success:
		print("Scene deleted successfully: ", path)


func _on_action_received(action: Dictionary) -> void:
	print("AI recommended action: ", action.get("action_type", ""))


func _on_chat_completed(response: String) -> void:
	print("AI Assistant: ", response)
```

## 6. Testing via Terminal (cURL Examples)

### 1. Create a Scene (`POST /v1/scene/create`):
```bash
curl -X POST http://localhost:8000/v1/scene/create \
  -H "Content-Type: application/json" \
  -d '{
    "project_path": "/home/piet/Documents/godot/game",
    "file_path": "scenes/enemy.tscn",
    "root_node_name": "Enemy",
    "root_node_type": "CharacterBody2D",
    "script_path": "res://scripts/enemy.gd"
  }' | jq .
```

### 2. Inspect / Read a Scene (`GET /v1/scene`):
```bash
curl -s "http://localhost:8000/v1/scene?project_path=/home/piet/Documents/godot/game&file_path=scenes/enemy.tscn" | jq .
```

### 3. Edit a Scene (`POST /v1/scene/edit`):
```bash
curl -X POST http://localhost:8000/v1/scene/edit \
  -H "Content-Type: application/json" \
  -d '{
    "project_path": "/home/piet/Documents/godot/game",
    "file_path": "scenes/enemy.tscn",
    "add_nodes": [
      {
        "name": "HitBox",
        "type": "Area2D",
        "parent": "."
      }
    ],
    "attach_script": {
      "node": "Enemy",
      "script_path": "res://scripts/advanced_enemy.gd"
    }
  }' | jq .
```

### 4. Delete a Scene (`POST /v1/scene/delete` or `DELETE /v1/scene`):
```bash
curl -X POST http://localhost:8000/v1/scene/delete \
  -H "Content-Type: application/json" \
  -d '{
    "project_path": "/home/piet/Documents/godot/game",
    "file_path": "scenes/enemy.tscn"
  }' | jq .
```

### 5. Ask AI to Generate & Execute a Scene Action (`POST /v1/act`):
```bash
curl -X POST http://localhost:8000/v1/act \
  -H "Content-Type: application/json" \
  -d '{
    "project_path": "/home/piet/Documents/godot/game",
    "prompt": "Create a level scene with a TileMap and a Player instance"
  }' | jq .
```
